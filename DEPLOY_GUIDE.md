# Getting polymathsolution.github.io live (free, ~10 minutes)

## Step 1 — Create the GitHub account
1. Go to https://github.com/signup
2. Email: cruz.laut@gmail.com (or any email you prefer)
3. **Username: `polymathsolution`** — this exact spelling is what makes your URL. It was available as of Aug 31, 2026, so do this soon before someone takes it.
4. Pick a password, verify the email, choose the **Free** plan.

## Step 2 — Create the website repository
1. Once logged in, go to https://github.com/new
2. Repository name: **`polymathsolution.github.io`** (exactly this — username + `.github.io` is what tells GitHub "this is my website")
3. Set it to **Public** (required for free GitHub Pages)
4. Check "Add a README file" (makes the next step easier)
5. Click **Create repository**

## Step 3 — Upload the website file
1. On your new repository page, click **Add file → Upload files**
2. Drag in the `index.html` file I gave you
3. Click **Commit changes** at the bottom

## Step 4 — Done
Wait 1–3 minutes, then visit:

**https://polymathsolution.github.io**

Your site is live. That's it.

## Updating the site later
Any time you want to change the site, just edit or re-upload `index.html`:
- On the repo page, click `index.html` → the pencil icon (✏️) → edit → Commit changes.
- Or ask Claude to produce a new version of the file and upload it the same way as Step 3.
Changes go live in ~1 minute.

## When you're ready for the real .com (later, optional)
- Buy `polymathsolution.com` (or any domain) from a registrar (~$10–12/yr: Cloudflare, Namecheap, Porkbun).
- In the repo: Settings → Pages → Custom domain → enter your domain, and point the domain's DNS at GitHub Pages (the registrar and GitHub both have guides).
- The site itself needs zero changes — same file, new address.
